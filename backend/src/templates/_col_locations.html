{# Storage-location hub (#160) as a collection tab: boxes (physical) + binders + decks. #}

Where your cards physically live. A card sits in one place — a box, a binder, or a deck — set from the card's page. For flexible, overlapping labels use tags. What's the functional difference between a box and a binder? Read more A box is a basic, bulk storage option where cards are managed in bulk via scryfall syntax and stacks— identical copies of cards with the same name from the same set, same printing, condition, and language etc. A binder is a special kind of storage meant to display individual cards, and can be shared publicly with share links.
